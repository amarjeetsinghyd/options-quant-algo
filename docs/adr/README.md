# Architecture Decision Records (ADRs)

This directory contains the Architecture Decision Records (ADRs) for the Options Quant Algo project.

## Documenting Decisions

We use the standard Nygard template for recording decisions:

* **Title:** Short noun phrase (e.g., "1. Record Architecture Decisions").
* **Context:** What is the context, constraints, and problem we are trying to solve?
* **Decision:** What is the selected solution/architecture change?
* **Consequences:** What is the impact (positive and negative) of this change?
* **Status:** Draft, Proposed, Accepted, Rejected, or Superseded.

All new ADR files should follow the naming format: `NNNN-title.md` where `NNNN` is a sequential 4-digit number.
